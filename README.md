# 창원 산업단지 AX 동향 모니터

**배포 주소: https://dbsthdud112-gif.github.io/changwon-ax-trend-monitor/**

창원 산업단지의 제조 AX · 지원사업 · 스타트업 관련 기사 목록을 넣으면, 분류 사전(분야 · 쟁점)으로 나눠 분야별 개수 · 월별 추이 · 쟁점별 목록과 분류 안 된 기사를 보여 주는 웹 도구.

신흥기술영향평가세미나(2026-2) 연구도구 ① "정책·기술 동향 모니터" 과제. 교수님 공표에 따라 혼자 진행.

## 목적

- 제조 AX 전환 · 산업단지 제안서의 "추진 배경 / 현황"에 쓸 근거 기사를 분야 · 쟁점별로 정리
- 분류 기준을 코드와 따로 둔 파일로 드러내, 무엇을 어떤 기준으로 셌는지 다른 사람이 확인하고 고칠 수 있게 함

## 사용법

1. 배포 주소를 연다 (또는 내려받은 저장소의 `docs/index.html`을 더블클릭)
2. 기사 목록을 넣는다 — 셋 중 하나
   - **예시 불러오기**: 예시 22건을 바로 넣음
   - **CSV 파일 고르기**
   - 칸에 **붙여 넣고** "붙여 넣은 내용 읽기"
3. 결과를 본다
   - 점검 줄: 총 건수 = 분류됨 + 미분류, 건너뛴 줄
   - 분야별 막대, 월별 추이 선 그래프 ("표로 보기"로 숫자 확인)
   - 쟁점별 목록: 쟁점 버튼으로 거르기, 제목 검색
   - 미분류 목록, 제목에 "창원"이 없는 기사 알림
4. **CSV 내보내기**: 지금 보이는 목록을 `date,title,url,분야,쟁점` 열로 저장

### 입력 형식

```csv
date,title,url
2026-01-06,"창원시, 2026년 제조 AI 전환 원년으로 선언",https://www.newspim.com/news/view/20260106000875
```

- 날짜는 `YYYY-MM-DD`. 제목에 쉼표가 있으면 따옴표로 묶음
- 빈 줄, 날짜 · 제목이 빠진 줄, 날짜 형식이 틀린 줄은 건너뛰고 줄 번호를 알려 줌
- 엑셀에서 저장할 때는 "CSV UTF-8"로 저장

### 분류 기준 고치기

분류 사전은 [`docs/dictionary.js`](docs/dictionary.js) 한 파일에 있음. 키워드를 더하거나 빼면 결과가 바로 바뀜.

- 제목에 키워드가 들어 있으면 그 분야 · 쟁점으로 셈
- 분야는 위에서부터 **첫 일치 하나**, 쟁점은 걸리는 것 **모두**
- 영문 키워드는 앞뒤에 다른 영문 글자가 없을 때만 셈 ("제조AI"는 걸리고 "MAIN"은 안 걸림)
- 분야가 하나도 안 걸리면 미분류

## 확인한 결과

예시 22건을 넣었을 때 (`예시/기대결과.md`의 손으로 센 값과 한 건씩 대조, 22건 모두 같음)

| 항목 | 값 |
|---|---|
| 총 건수 | 22 = 분류됨 19 + 미분류 3 (처음 버전: 17 + 5) |
| 분야 | AI·AX 15 · 스마트공장·자동화 0 · 디지털트윈 0 · 주력 업종 2 · 산업단지 고도화 2 |
| 쟁점 | 지원사업·공모 12 · 규제·제도 3 · 투자·스타트업 1 · 인력·교육 1 |
| 월별 (1~10월) | 2 · 5 · 0 · 1 · 5 · 1 · 1 · 3 · 1 · 3 |
| 제목에 "창원" 없음 | 3 |

그 밖에 확인한 것

- 다른 입력: 빈 줄 · 날짜 없음 · 날짜 형식 틀림 · 제목 없음 줄이 줄 번호와 이유로 표시되고 나머지만 읽힘
- 왕복: 내보낸 CSV를 다시 넣어도 같은 결과
- 분류 사전에 키워드 하나를 더하면 미분류 기사가 그 분야로 옮겨 감
- 배포 주소에서 "예시 불러오기"로 위 숫자가 그대로 나옴

## 한계

- **제목만 봄**: 본문은 넣지 않아서, 제목에 키워드가 없으면 내용이 맞아도 분류되지 않음
- **분야 첫 일치 하나**: 분야 순서가 결과를 바꿈. 예시에서 AI·AX가 15건으로 몰리고, 방산 · SMR · 자율제조 기사도 제목에 AI가 있으면 AI·AX로 감
- **산업단지 기사의 미분류**: 처음 버전에서 예시 3 · 9 · 12번이 분야 키워드가 없어 미분류. 2차에서 "산업단지 고도화" 분야를 더해 3 · 12번은 분류했고, 9번(스타트업 지원)은 분야가 아닌 쟁점이라 미분류로 둠
- **낱말 일치의 한계**: 같은 낱말이 다른 뜻으로 쓰이거나(예: "선정", "지정"), 키워드 표기가 다르면 놓치거나 잘못 셈
- **"창원" 확인은 제목만**: 제목에 "창원"이 없어도 창원 기사일 수 있음 (예: "산업단지 AX 분과")
- **기사 수집은 손으로**: 도구가 기사를 모으지 않음. 어떤 기사를 넣었느냐가 결과를 정함
- **확인 못 한 것**: 엑셀에서 UTF-8이 아닌 형식으로 저장한 CSV (한글이 깨질 수 있음)
